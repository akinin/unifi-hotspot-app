# Wiren Board SMS Gateway

Приложение запускает SMS API, тестовый UniFi hotspot-портал и административную
панель внутри Home Assistant. Админка открывается через Ingress и доступна
только администраторам Home Assistant.

## Безопасный параллельный запуск

Начальные настройки специально не заменяют действующий LXC:

- API опубликован на порту `18088`, портал — на `18880`;
- `unifi_dry_run` включён, поэтому приложение не меняет состояние клиентов UniFi;
- база и сгенерированный `app_secret` хранятся в `/data` и попадают в резервную
  копию приложения;
- пустой `api_token` блокирует защищённые HTTP-методы;
- отправка SMS заработает только после ввода учётных данных защищённого MQTT.

Для испытаний укажите MQTT `10.10.100.5:1884`, отдельного пользователя и пароль.
Не переключайте UniFi captive portal со старого LXC, пока не проверены отправка
SMS, OTP, журнал и восстановление из резервной копии.

## Основные параметры

- `api_token` — токен HTTP API. Передавайте его как `Bearer <token>`.
- `app_secret` — секрет OTP. Если оставить пустым, он будет сгенерирован и
  сохранён в `/data/app_secret`.
- `wb_mqtt_*` — защищённое MQTT-подключение к Wiren Board.
- `unifi_dry_run` — запрет изменяющих запросов UniFi. Отключайте только перед
  финальным тестом.
- `unifi_api_key` — предпочтительный способ подключения к UniFi. Локальные
  логин и пароль оставлены для совместимости.
- `unifi_verify_tls` — проверка сертификата UniFi; рекомендуется включить после
  установки доверенного сертификата.

## Адреса

- Админка: кнопка **Открыть веб-интерфейс** на странице приложения.
- API: `http://<адрес-Home-Assistant>:18088`.
- Тестовый портал: `http://<адрес-Home-Assistant>:18880`.

Проверка API:

```bash
curl http://HOME_ASSISTANT_IP:18088/health
```

## Переключение с LXC

1. Сделайте резервную копию приложения.
2. Проверьте SMS через админку.
3. Проверьте OTP на тестовом MAC при включённом `unifi_dry_run`.
4. Кратковременно отключите dry-run и проверьте тестового клиента.
5. Только после этого измените адрес captive portal в UniFi.
6. Старый LXC остановите, но не удаляйте до завершения периода наблюдения.
