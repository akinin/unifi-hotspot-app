# UniFi Hotspot

Вкладка **Просмотр** показывает актуальную страницу входа Hotspot в мобильной
или широкой рамке. Предпросмотр изолирован: из него нельзя отправить SMS или
изменить доступ клиента.

Приложение запускает UniFi hotspot-портал с SMS-авторизацией, API и
административную панель внутри Home Assistant. Админка открывается через
Ingress и доступна только администраторам Home Assistant.

SMS Gateway является встроенным транспортом портала. Доступны два режима:

- `mqtt` — отправка через Wiren Board и обязательный `send_sms.js`;
- `mmcli` — отправка через подключённый к Home Assistant USB-модем.

Интеграция Wiren Board Discovery продолжает самостоятельно регистрировать
службу отправки SMS в Home Assistant. Приложение её не дублирует и использует
собственный транспорт только для портала, OTP и HTTP API.

В веб-интерфейсе доступны отдельные вкладки **WB** и **USB**. Тестовая отправка
на каждой вкладке всегда использует соответствующий транспорт независимо от
`sms_backend`; этот параметр выбирает только транспорт OTP/API по умолчанию.

## Безопасный параллельный запуск

Начальные настройки специально не заменяют действующий LXC:

- API опубликован на порту `18088`, портал — на `18880`;
- `unifi_dry_run` включён, поэтому приложение не меняет состояние клиентов UniFi;
- база и сгенерированный `app_secret` хранятся в `/data` и попадают в резервную
  копию приложения;
- пустой `api_token` блокирует защищённые HTTP-методы;
- отправка SMS заработает только после ввода учётных данных защищённого MQTT.

Для испытаний укажите MQTT `10.10.100.5:1884`, отдельного пользователя и пароль.
Не переключайте UniFi captive portal со старого LXC, пока не проверены отправка
SMS, OTP, журнал и восстановление из резервной копии.

## Обязательный скрипт на Wiren Board

Для MQTT-режима на Wiren Board **обязательно** должен работать сценарий
[`send_sms.js`](../wirenboard/send_sms.js). Без него приложение сможет
подключиться к MQTT, но команда из топика
`/devices/sms_sender/controls/send/on` не будет передана в `Notify.sendSMS()` и
SMS не отправится.

Установка на Wiren Board:

1. Скопируйте `wirenboard/send_sms.js` в `/etc/wb-rules/send_sms.js`.
2. Убедитесь, что SIM-карта и модем настроены в веб-интерфейсе Wiren Board и
   штатная отправка SMS работает.
3. Перезапустите движок правил:

   ```bash
   systemctl restart wb-rules
   ```

4. Проверьте создание виртуального устройства и отсутствие ошибок:

   ```bash
   systemctl status wb-rules --no-pager
   journalctl -u wb-rules -n 100 --no-pager
   ```

5. Проверьте отправку тестовой команды через локальный MQTT:

   ```bash
   mosquitto_pub -h 127.0.0.1 \
     -t /devices/sms_sender/controls/send/on \
     -m '+79991234567;Тест SMS Gateway'
   ```

После успешной отправки в Wiren Board появится устройство **SMS Sender**, а в
контроле **Результат последней отправки** — значение `Команда отправки передана`.
Замените тестовый номер на собственный.

## USB-модем

1. Подключите совместимый USB-модем к хосту Home Assistant.
2. В настройках приложения задайте `sms_backend: mmcli`.
3. Оставьте `mmcli_modem_id: any` для автоматического выбора или укажите ID.
4. Перезапустите приложение и проверьте раздел **SMS Gateway**.

При выборе USB в интерфейсе используется отдельный фиолетовый логотип и
запускается ModemManager. Для возврата на Wiren Board укажите `sms_backend: mqtt`.

## Основные параметры

- `api_token` — токен HTTP API. Передавайте его как `Bearer <token>`.
- `app_secret` — секрет OTP. Если оставить пустым, он будет сгенерирован и
  сохранён в `/data/app_secret`.
- `wb_mqtt_*` — защищённое MQTT-подключение к Wiren Board.
- `unifi_dry_run` — запрет изменяющих запросов UniFi. Отключайте только перед
  финальным тестом.
- `unifi_api_key` — предпочтительный способ подключения к UniFi. Локальные
  логин и пароль оставлены для совместимости.
- `unifi_verify_tls` — проверка сертификата UniFi; рекомендуется включить после
  установки доверенного сертификата.

## Адреса

- Админка: кнопка **Открыть веб-интерфейс** на странице приложения.
- API: `http://<адрес-Home-Assistant>:18088`.
- Тестовый портал: `http://<адрес-Home-Assistant>:18880`.

Проверка API:

```bash
curl http://HOME_ASSISTANT_IP:18088/health
```

## Переключение с LXC

1. Сделайте резервную копию приложения.
2. Проверьте SMS через админку.
3. Проверьте OTP на тестовом MAC при включённом `unifi_dry_run`.
4. Кратковременно отключите dry-run и проверьте тестового клиента.
5. Только после этого измените адрес captive portal в UniFi.
6. Старый LXC остановите, но не удаляйте до завершения периода наблюдения.
