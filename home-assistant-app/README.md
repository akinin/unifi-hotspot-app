# UniFi Hotspot

Гостевой портал UniFi Network с авторизацией посетителей по одноразовому
SMS-коду. Приложение работает внутри Home Assistant, открывает администрирование
через защищённый Ingress и поддерживает два независимых транспорта SMS.

## Возможности

- авторизация гостей UniFi по одноразовому SMS-коду;
- отправка SMS через **Wiren Board/MQTT** или **USB-модем/ModemManager**;
- просмотр активных клиентов и ранее авторизованных устройств UniFi;
- продление доступа, отзыв авторизации и блокировка клиента;
- архив авторизаций и журнал отправленных SMS;
- сохранение последнего известного IP отключившегося клиента;
- настройка текста, фона, логотипа и его размера с живым предпросмотром;
- ограничение срока действия и количества попыток ввода OTP;
- HTTP API для интеграции с Home Assistant и внешними автоматизациями;
- резервное копирование настроек, базы, журналов и оформления средствами
  Home Assistant.

## Разделы веб-интерфейса

| Раздел | Назначение |
|---|---|
| **Hotspot** | Состояние UniFi, активные гости, архив и оформление портала |
| **WB** | Подключение MQTT, тестовая SMS, обязательный сценарий WB и журнал |
| **USB** | Состояние модема, оператор, сигнал и тестовая отправка SMS |

## Требования

- Home Assistant OS с поддержкой приложений;
- UniFi Network Controller, доступный из сети Home Assistant;
- Wiren Board с установленным `send_sms.js` **или** совместимый USB-модем;
- отдельные учётные данные UniFi и MQTT с минимально необходимыми правами.

## Начало работы

1. Откройте вкладку **Конфигурация**.
2. Выберите транспорт SMS: `mqtt` для Wiren Board или `mmcli` для USB-модема.
3. Заполните параметры выбранного транспорта и UniFi Network.
4. Сначала оставьте включённым **Тестовый режим UniFi**.
5. Запустите приложение и проверьте тестовую SMS в разделе **WB** или **USB**.
6. После проверки отключите тестовый режим и выполните авторизацию одного
   тестового клиента.
